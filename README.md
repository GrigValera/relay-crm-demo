# Релей — обработка входящих обращений

Демонстрационный кабинет CREATOR для команд продаж и поддержки. Менеджер открывает обращение вместе с исходным текстом, каналом и назначенной командой, передаёт его в демо-CRM и может проверить результат в журнале.

## Сценарий для ревью

1. В «Маршрутизации» назначьте электронной почте команду «Поддержка» и сохраните правила.
2. Добавьте тестовую заявку с канала «Электронная почта».
3. В карточке заявки проверьте текст, канал и назначенную команду. Выберите «Имитировать сбой CRM» и нажмите «Передать в демо-CRM».
4. Нажмите «Повторить передачу». После успеха у заявки появится один номер CRM и связь с событиями в журнале.

HTML, CSS и JavaScript. Демо использует вымышленные данные, назначает команду по входному каналу и имитирует передачу без внешних запросов. Правила, обращения и журнал хранятся в браузере. Уже переданная заявка сохраняет единственный идентификатор CRM. Применение нового правила сохраняет команду ранее полученных заявок.

## Запуск

В каталоге проекта выполните `python -m http.server 4213`, затем откройте `http://localhost:4213/`. Сборка и сторонние зависимости не требуются.
